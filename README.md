# LeagueAPI
This program is going to use the public Riot API to find user data based on their Riot ID. This data will be used by the user to scout out their teammates and opponents when loading into a League of Legends game. My MVP is to have an easily readable output of data so that the player can easily read about their teammates and opponents during the game. This program will use Java, HTTP, and Google Gson. It will receive a user input, access the Riot API, receive the data based on the requested Riot ID, and send the data back to the user. To do this, it will utilize HTTP to access the Riot API and Google Gson to extract the data.
